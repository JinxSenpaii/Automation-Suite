01

Recruitment — Job Application Form Log (Intake)

Validates candidate submissions and PDF uploads, checks Google Sheets to block duplicate applications for the same role, uploads the CV to Google Drive, logs the candidate with status new, and returns an instant confirmation page.

Trigger: Form Trigger Duplicate Check Google Drive + Sheets
02

Recruitment — Batch Evaluation (AI Screening)

Runs hourly (or manually) to loop through pending applications, downloads each CV, extracts text with an OCR fallback for scanned PDFs, evaluates candidates using structured AI scoring & auto-fixing JSON schema validation, emails interview invites or polite declines, flags borderline cases for HR manual review, and updates the tracking sheet.

Trigger: Every Hour + Manual PDF Text + OCR Fallback Structured AI Scoring Gmail Automation
03

Recruitment — RAG Policy Assistant

Public hosted chat agent powered by Google Gemini Chat Model, conversation memory, and vector similarity search over the hr_policies knowledge base. Responds accurately in English and Arabic with policy source citations and escalates out-of-scope questions to HR.

Trigger: Public Chat (CORS) Gemini Embeddings In-Memory Vector Store
04

Policy Loader (Persistent Knowledge Sync)

Solves vector store volatility across Docker restarts by automatically fetching HR policy files from Google Drive on n8n startup, every morning at 7:00 AM, or on manual trigger—clearing stale vectors, chunking text (200-char overlap), and re-embedding into hr_policies.

Triggers: n8n Start · Daily 7 AM · Manual Auto-Reload Vector Store Clear Store Enabled
05

Recruitment — Error Handler & Queue Heartbeat

Centralized reliability pipeline attached to all workflows: classifies runtime errors, applies alert throttling to avoid inbox floods, logs incidents to an Error Log sheet, sends a daily 8:00 AM digest, and runs a 2-hour heartbeat monitor to detect stuck applications.

Triggers: Error · Daily 8 AM · Every 2h Alert Throttling Stuck-Queue Heartbeat
